Things I've built

A selection of tools, experiments and event-tech contraptions — from open-source macOS hacks to utility web tools.

RedPill 2026 (Metal)

The classic 3D Matrix digital rain screensaver for macOS, re-rendered with Metal. A full Swift port of the OpenGL version — one shared vertex buffer and a single draw call per frame, custom shaders with linear fog, and native Retina resolution.

swift metal shaders macOS GPL-3.0

RedPill-2025

A macOS Matrix screensaver from the past, kept alive. Universal binary (Apple Silicon + Intel) with modern compatibility fixes for Sonoma, Sequoia and macOS 26 — including a workaround for the infamous CPU-hungry legacyScreenSaver process.

objective-c opengl universal-binary macOS GPL-3.0
